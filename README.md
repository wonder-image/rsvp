## Scarica i file

Esegui il comando nel terminale dopo l'installazione di wonder-image/new

```
gh repo clone wonder-image/getrix git-tmp
cp -R git-tmp/src/ .
rm -rf git-tmp
clear
echo "\nRicarica tutti i file e esegui \033[1m [https://www.${PWD##*/}/update/](https://www.$%7Bpwd#%23*/%257D/update/) \033[0m
\n\n"
```
